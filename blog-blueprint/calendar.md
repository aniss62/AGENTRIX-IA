# Calendrier éditorial

Le plan au-dessus des articles individuels. Les clusters de sujets construisent l'autorité ;
le calendrier garde les signaux de fraîcheur forts (les moteurs IA favorisent le contenu mis à
jour dans les ~30 derniers jours).

## Mix de contenu (60/30/10)
- **60% Cœur / evergreen** — pages piliers + guides pratiques sur les 4 familles de services.
- **30% Tendance / actu** — analyses sur l'actualité IA agentique pertinente pour des dirigeants
  (nouveaux modèles, réglementation, adoption sectorielle).
- **10% Expérimental** — études de cas chiffrées issues des déploiements Agentrix, prises de
  position à contre-courant du hype IA.

## Clusters de sujets (pilier & satellites)
| Pilier | Satellites (exemples de départ) |
|--------|----------------------------------|
| Automatisation de workflows | Relances client automatisées · Rapports automatiques · Synchronisation d'outils (CRM/e-mail) · Combien coûte une tâche répétitive non automatisée · Automatisation vs. no-code (Zapier/Make) : quand passer à un agent |
| Scraping & leads qualifiés | Qualification de leads par agent IA · Enrichissement de données prospects · Construire un pipeline de leads qui se remplit seul · Scraping éthique et conformité RGPD · Scoring de leads : règles vs. agent |
| Sites à forte conversion | Ce qui fait doubler un taux de conversion · Agents IA sur un site (chat, qualification) · Landing page vs. site agentique · Mesurer l'impact d'un agent sur la conversion |
| Agents de raisonnement | Différence agent IA vs. chatbot vs. RPA · Quand garder un humain dans la boucle · Découper un objectif métier en étapes pour un agent · Cas où un agent de raisonnement échoue (et pourquoi) |

## Cadence `[À CONFIRMER]`
- Cible : 1 à 2 articles/semaine pour commencer (ajuster selon la capacité de relecture).
- Cycle de rafraîchissement : revoir chaque article publié tous les **30 jours** ; mettre à jour
  les chiffres et la date de modification.

## File d'attente
Suivie dans `blog-blueprint/content/topic-queue.md`. Statuts : `intake` → `research` →
`draft` → `optimized` → `qa-pass` → `published`.

## Veille de dépréciation
Revoir périodiquement les articles publiés pour repérer les statistiques datées, les pages
orphelines (aucun lien interne) et la cannibalisation de mots-clés entre deux articles proches.
